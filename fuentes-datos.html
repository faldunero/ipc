✅ Modelo de Predicción Multi-Fuente

El sistema de predicción del IPC se nutre de múltiples fuentes de datos oficiales y confiables. Cada fuente tiene una fecha de actualización y un estado de disponibilidad. El modelo utiliza walk-forward validation con 36+ meses de datos históricos y ARIMA para proyecciones mensuales.

📈 Composición del Modelo

ARIMA (AutoRegressive Integrated Moving Average) es el algoritmo principal que utiliza:

• Datos Históricos (36 meses): IPC mensual variación desde Banco Central
• Indicadores Adelantados: Mindicador.cl (dólar, UF, tasas)
• Precios Agrícolas: ODEPA (frutas, verduras)
• Precios de Bienes: Cámaras de Comercio (ropa, electrónica, muebles)
• Validación: Walk-forward backtesting con 24 meses de predicciones validadas

Precisión del Modelo: MAE 0.36%, RMSE 0.49%, Aciertos Direccionales 47.8%
