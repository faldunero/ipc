¿QUÉ VES AQUÍ?
Este dashboard monitorea cómo nuestro modelo ensemble se desempeña contra datos reales del Banco Central de Chile. Cada mes se entrena el modelo con datos históricos y se compara su predicción contra el IPC real publicado. Las métricas muestran qué tan preciso es nuestro modelo y cuál componente (ARIMA, XGBoost o LSTM) contribuye mejor.

📊 Comparación de Modelos
MAE por Modelo
Error Absoluto Medio (MAE)

Mide en promedio cuánto se desvió cada modelo del valor real.

Lectura: Barras más cortas = mejor. El ensemble es el promedio ponderado.

Ejemplo: Si ARIMA=0.30pp y XGBoost=0.35pp, significa que ARIMA falló por 0.30pp en promedio.

RMSE por Modelo
Error Cuadrático Medio Raizado (RMSE)

Métrica que penaliza desviaciones grandes más que pequeñas.

Lectura: Si RMSE es mucho más alto que MAE, hubo un error grande que distorsiona el promedio.

Ejemplo: MAE=0.30pp pero RMSE=0.60pp → un mes hubo error muy grande.

Aciertos Dirección (%)
Tasa de Aciertos en Dirección

¿Cuántas veces predijo correctamente si sube (+) o baja (-) el IPC?

Lectura: 50% = azar. >60% = bueno. >70% = excelente.

Ejemplo: Si 10 de 13 meses predijo el signo correcto → 77% de acierto.

Predicción vs Realidad (Timeline)
Línea Azul (Predicción) vs Línea Naranja (Realidad)

Muestra qué tan cerca sigue la predicción a la realidad a través del tiempo.

Lectura: Líneas próximas = buen modelo. Líneas alejadas = errores grandes.

Interpretación: Detecta si el modelo pierde precisión en ciertos períodos.

⚙️ Componentes del Modelo Ensemble

🔴 ARIMA - Autorregresivo (40% del Ensemble)

Qué hace: Modela cómo el IPC de hoy depende del IPC pasado. Excelente para capturar tendencias y ciclos.
Ventaja: Muy estable, pruebas estadísticas, poco riesgo de sobreentrenamiento.
Desventaja: Asume relaciones lineales. No captura cambios abruptos.
Mejor en: Tendencias predecibles, períodos de estabilidad.

🟢 XGBoost - Aprendizaje Automático (40% del Ensemble)

Qué hace: Árbol de decisión que aprende relaciones complejas entre variables (lags, tendencias, estacionalidad).
Ventaja: Detecta cambios no-lineales, efectos estacionales, elasticidades de precio.
Desventaja: Puede sobreentrenarse si no se calibra bien.
Mejor en: Cambios estructurales, efectos estacionales (rebajas, demanda).

🔵 LSTM - Red Neuronal Recurrente (20% del Ensemble)

Qué hace: Red neuronal que detecta patrones temporales complejos y cambios endógenos en volatilidad.
Ventaja: Excelente para capturar reversiones a media, transiciones de régimen.
Desventaja: Menos estable que ARIMA, requiere más datos, peso menor (20%) en ensemble.
Mejor en: Transiciones de régimen, patrones sutiles no obvios.
